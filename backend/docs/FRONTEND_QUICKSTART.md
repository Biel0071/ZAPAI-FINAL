# Frontend Quickstart

## Location
- frontend/

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- Zustand state store
- Framer Motion
- Recharts
- React Flow

## Run
1. cd frontend
2. npm install
3. npm run dev

The Vite dev server proxies backend API routes to http://localhost:4000.

## Current Pages
- Dashboard
- Inbox
- Contacts
- Campaigns
- Automation
- Analytics
- AI Settings
- System Settings
